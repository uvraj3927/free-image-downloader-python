# 🖼️ Free Image Downloader using Python

A simple desktop application built using Python and Tkinter that allows users to download images directly from image URLs.

This project uses the `requests` library to fetch images from the internet and save them locally.

---

### Features

- Simple GUI interface
- Download images using URL
- Saves images automatically
- Beginner-friendly Python project
- Lightweight desktop application

---

### Technologies Used

- Python
- Tkinter
- Requests Library

---

### How It Works

1. Enter an image URL
2. Click the **Download** button
3. The image gets downloaded
4. Image is saved as `image.jpg`
